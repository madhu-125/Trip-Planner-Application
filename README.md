✈️ Trip Planner

A web-based Trip Planner application developed to help users organize and manage their travel plans.

📌 Project Overview

Trip Planner is a travel management project built using Java, Spring Boot, and Maven. The repository contains separate folders for the user interface and backend application.

🛠️ Technologies Used

- Java
- Spring Boot
- Maven
- HTML, CSS and JavaScript (if used in the UI)

⚙️ Backend Setup

1. Clone the repository:

git clone https://github.com/madhu-125/Trip-Planner.git

2. Open the backend folder:

cd Trip-Planner/Trip-planner

3. Build the project:

mvnw.cmd clean install

4. Run the Spring Boot application:

mvnw.cmd spring-boot:run
